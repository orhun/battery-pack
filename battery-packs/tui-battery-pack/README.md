# tui-battery-pack

A [battery pack](https://crates.io/crates/battery-pack) for building full-screen terminal user interfaces with [Ratatui](https://ratatui.rs/).

## Quick Start

```sh
cargo bp new tui --template app
```

The starter app includes terminal setup and cleanup, a keyboard event loop, and a small task list screen rendered through Ratatui's test backend.
